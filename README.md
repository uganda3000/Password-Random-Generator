# Password Generator

Простой генератор паролей на Python. Проект создан для учебных и личных целей: он позволяет быстро получить случайный пароль из букв, цифр и символов.

> **Важно!** Автор не несёт ответственности за любые случаи взлома, подбора, утечки или компрометации аккаунтов, а также не гарантирует надёжность, стойкость и безопасность сгенерированных паролей. Проект предоставляется **как есть (AS IS)**, без каких-либо гарантий. Используйте его на свой страх и риск.

---

## Возможности

- Генерация пароля заданной длины.
- Использование:
  - заглавных латинских букв;
  - строчных латинских букв;
  - цифр;
  - специальных символов.
- Не требует сторонних библиотек.
- Простой запуск из командной строки.

---

## Требования

- Любая ОС: Windows, macOS, Linux
